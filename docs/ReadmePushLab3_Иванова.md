# Описание
В ходе работы был создан локальный Git-репозиторий и выполнена привязка к удалённому репозиторию GitHub

## Команды
```bash
git remote add origin https://github.com/anfisa6767/Lab3-MarkdownLaTeX_-.git
git push -u origin master
```

## Результат
создана ветка `master`

локальная ветка настроена на отслеживание `origin/master`

первый коммит отправлен на GitHub.
