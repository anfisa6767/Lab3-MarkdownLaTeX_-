### Заголовок третьего уровня
#### Что такое Markdown
Markdown - это лёгкий язык разметки, который используется для оформления README-файлов, документации, отчётов и научных текстов.

#### Где применяется Markdown
Markdown используется в GitHub, VS Code, Obsidian, документации проектов, блогах, заметках и сообщениях.

#### Зачем Markdown нужен разработчикам
Он позволяет быстро оформлять документацию, README-файлы, комментарии и заметки, которые легко читать в обычном тексте и преобразовывать в HTML, PDF и другие форматы.
