## Введение

Markdown — это простой язык разметки для быстрого форматирования текста. Он легко преобразуется в HTML и используется для документации, постов и веб-контента.
---

## Основные возможности Markdown

Markdown поддерживает заголовки, списки, ссылки, выделение текста, блоки кода и таблицы. Синтаксис остаётся читабельным даже без рендеринга.

---

## Пример форматирования

**Жирный текст**, *курсив*, `код`, списки и цитаты делают документацию удобной и структурированной.
